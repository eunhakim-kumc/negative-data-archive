기록 기여하기

고려대학교 구성원은 제출 시스템에서 학교 메일 주소로 로그인해 직접 등록할 수 있습니다. 비밀번호는 없고, 메일로 받은 링크를 누르면 바로 들어갑니다. 교외 연구자의 기여나 기존 기록에 대한 문의는 운영자에게 연락해 주세요.

기록 원칙 — 조건을 특정할 수 있을 만큼 적습니다. "이 항체는 안 됩니다"가 아니라 "이 lot을, 이 고정 조건에서, 이 조직에 썼을 때 안 됩니다". 음성 데이터는 양성 대조가 살아 있을 때만 의미를 가집니다.

읽는 분께 — 각 기록은 특정 조건에서의 단일 관찰입니다. 일반적인 결론이 아니며, 다른 조건에서는 다르게 동작할 수 있습니다. 중요한 결정 전에는 기록된 조건을 직접 확인하시기 바랍니다.
